# Treasure Hunt Adventure Game

A text-based adventure game developed in C as part of a university programming project.

## About the Project

Explore a mysterious cursed temple, solve riddles and puzzles, avoid dangerous traps, encounter enemies, collect useful items, and uncover the secrets hidden within the temple.

## Features

- Room-based exploration and movement
- Player health and inventory management
- Riddles, puzzles, and traps
- Enemy encounters and challenges
- Treasure and artifact discovery
- Save and load game progress
- Terminal interface with ASCII art and colored text
- Slow-printing dialogue for a more immersive experience

## Technologies Used

- **Programming language:** C
- **Development environment:** Code::Blocks
- **Libraries:** Standard C libraries and Windows API for delay effects

## How to Run

1. Download or clone this repository.
2. Open `Treasure_hunt.c` in Code::Blocks or another compatible C IDE.
3. Compile the source file using a C compiler on Windows.
4. Run the compiled program and start your adventure.
